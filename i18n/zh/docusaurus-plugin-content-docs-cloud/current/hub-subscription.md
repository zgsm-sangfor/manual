# 知识中心订阅教程：从网页订阅到 csc 自动同步

## 第一步：找到你想要的能力

1. 知识中心首页是一排排的能力卡片，可以**搜索**（顶部搜索框）或**按分类浏览**。

<img src={hub_image1} alt="知识中心首页" width="750" />

2. 点开任意一张卡片，进入**详情页**。详情页能看到：
   - 这个能力是干什么的（描述）
   - **健康度 / 评估详情 / 综合评分**（帮你判断质量好不好）
   - 一个醒目的 **「订阅」** 按钮（带个小铃铛图标和订阅数）

<img src={hub_image2} alt="能力详情页" width="750" />

## 第二步：点击「订阅」

### 通用做法（技能 / 命令 / 子智能体都一样）

直接点详情页（或卡片上）的 **「订阅」** 按钮即可。

- 点完按钮会变成 **「取消订阅」**，订阅数 +1，铃铛会抖一下 —— 这就成功了。
- 不想要了？再点一次 **「取消订阅」** 就取消了。

<img src={hub_image3} alt="订阅按钮" width="700" />

就这么简单。**订阅本身不需要下载、不需要装环境**，它只是把这个能力记到你账号上。真正的下载交给 csc 自动完成（第四步）。

### 不同类型的小差异（看清楚再点）

不是所有能力都可以「一键订阅」。

#### MCP 服务 —— 部分要先填参数

有些 MCP 需要你先填一点东西（比如本地路径、API token）才能用。这时详情页会出现一块 **「参数配置」**，并提示：

> "该 MCP 服务需要你先填写一些值（如本地路径或 API token）才能使用。"

<img src={hub_image4} alt="MCP参数配置" width="750" />

操作顺序：
1. 在 **「参数配置」** 里把要求的值填好（如「路径」、「参数 1」等）
2. 点 **「保存」**（保存成功会变成 **「已保存」**）
3. 这时 **「订阅」** 按钮才能点

## 第三步：打开并登录 csc

### 1. 打开 csc

在终端里输入 `csc` 回车启动：

- **第一次启动**会有个简单的引导：选个配色主题、看一眼安全提示、问你要不要启用终端优化 —— 按提示一路选下去就行（以后都能用 `/theme`、`/config` 改回来）。
- 启动后你会进入一个**交互式对话界面**：最下面是输入框，平时在这里跟 AI 对话；凡是以 `/` 开头的就是「命令」（比如下面要用的 `/login`、`/hub`）。输入 `/` 时会自动弹出命令候选列表，不用背。

<img src={hub_image5} alt="csc界面" width="650" />

### 2. 登录 /login

在输入框输入并回车：

```
/login
```

- 它会弹出登录框并**自动打开浏览器**走统一身份（SSO）登录；如果浏览器没自动开，按提示把链接复制到浏览器打开。
- 登录成功会提示 **Login successful**，按 `Esc` 关掉对话框即可。凭证会自动保存到本地（`~/.costrict/csc-auth.json`），以后不用反复登录。

<img src={hub_image6} alt="登录对话框" width="600" />

<img src={hub_image7} alt="登录成功" width="550" />

## 第四步：让 csc 自动同步（你几乎什么都不用做）

这是最省心的一步 —— **你不需要手动下载任何东西**。

- **技能 / 命令 / 子智能体 / MCP**：csc **每次启动时**会自动去网页那边对账，把你新订阅的拉下来并激活。
- **插件 Plugin**：csc 启动时同步一次，之后还会**定时轮询**（默认每 60 秒）持续保持同步。

也就是说：**网页上点完订阅 → 重启一下 csc（或等一会儿）→ 东西就到了。**

### 用 /hub 面板查看和管理订阅

在 csc 输入框里输入并回车：

```
/hub
```

<img src={hub_image8} alt="Hub面板" width="600" />

- **顶部**有一行提示：云端订阅项目，如需订阅请访问 [CoStrict Cloud](https://zgsm.sangfor.com/cloud)（这就是网页知识中心的入口）。
- **4 个标签页**：Skills（技能）、Agents（子智能体）、Commands（命令）、MCP。

> 如果你在网页上取消了某些订阅、但本地还激活着，下次打开 `/hub` 会弹一个 **Cloud favorites updated** 提示，问你要 **Unload all**（一并卸载）还是 **Keep local config**（保留本地），按需选即可。

想更直接验证的，可以看本地文件，例如：`ls ~/.costrict/skills/<能力名>/`，里面有 `SKILL.md` 就对了。普通用户不用关心这个。

## 第五步：开始使用

同步好之后就能直接用了。在 csc 输入框里：

- **技能 / 命令**：直接输入 `/能力名` 触发。比如订阅了一个叫 `code-review` 的技能，就输入 `/code-review`。
- **不记得名字？** 输入 `/help` 看所有可用命令；输入 `/skills` 看已装的技能列表。
- **子智能体（Agent）**：用 `/agents` 查看和管理。
- **MCP 服务**：用 `/mcp` 管理，`/mcp enable <服务名>` 启用某个服务，启用后 AI 就能调用它提供的工具。
- **插件（Plugin）**：在对话界面里用 `/plugin` 打开插件管理面板；刚装完不想重启的话，用 `/reload-plugins` 让它立即生效。

关于「自动 / 手动」调用（订阅技能、命令时选的那个）：

- 选了 **「允许 AI 自动调用」**：你正常聊天，AI 觉得需要时会**自己用**这个技能；你也可以手动 `/能力名` 触发。
- 选了 **「仅手动调用」**：AI 不会自作主张，**只有你输入 `/能力名`** 才会用。

到这里，整个「网页订阅 → 本地可用」的闭环就完成了。

## csc 命令速查（贴手边）

| 命令 | 作用 |
|---|---|
| `csc` | 在终端启动 csc（进入对话界面） |
| `/login` | 登录（务必与网页同一账号） |
| `/status` | 查看当前登录账号 / 连接状态 |
| `/hub` | 打开知识中心面板，查看 / 启停已订阅的资源 |
| `/help` | 列出所有可用命令 |
| `/skills` | 查看已安装的技能 |
| `/能力名` | 触发某个技能 / 命令（如 `/code-review`） |
| `/agents` | 管理子智能体 |
| `/mcp` | 管理 MCP 服务（`/mcp enable <服务名>` 启用） |
| `/plugin` | 管理插件（或终端 `csc plugin install <名>@costrict-plugins`） |
| `/reload-plugins` | 不重启就让新装的插件即时生效 |

## 常见问题（FAQ）

**Q1：我在网页订阅了，但 csc 里看不到？**

- 检查 csc 和网页是不是同一个账号（最常见原因）
- 重启一下 csc（技能/命令是启动时同步的）
- 插件稍等一会儿（最长约 60 秒一轮）
- 用 `/hub` 看状态，如果是 Cloud 就是还没拉下来，重启即可

**Q2：订阅按钮是灰的点不动？**

- 多半是 MCP 需要先填「参数配置」并保存；或这个 MCP 依赖某个插件，要去订阅那个插件。按按钮旁的提示文字操作。

**Q3：取消订阅后本地会怎样？**

- 取消订阅后，csc 下次对账会相应处理本地副本；想再用重新订阅即可。
