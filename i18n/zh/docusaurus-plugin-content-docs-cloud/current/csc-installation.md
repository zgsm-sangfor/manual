# CSC 安装手册（小白上手版）

从打开终端到第一次成功对话｜小白操作版

**适用：** 第一次安装 CSC 的 Windows、macOS、Linux 用户 · **更新：** 2026-07-03

> **先说结论：** 核心安装只有 1 条命令。多数已装好 Node.js 的电脑，约 3 分钟可完成；如果需要先安装 Node.js，或公司网络有限制，会需要更长时间。

## 开始前：30 秒自检

你需要：能联网的电脑、一个终端（命令行窗口）、CoStrict 账户。

先在终端依次输入下面命令。每输入一行就按一次 Enter（回车）：

```bash
node -v
npm -v
```

> 执行完命令，看到版本号例如 `v24.x.x` 和 `11.x.x`，就可以继续。若提示"找不到命令 / 不是内部或外部命令"，直接看下方的**异常处理** A 项。
>
> **Windows 用户**还需要看到 git 的版本号，例如 `git version 2.x.x`。CSC 在 Windows 上需要 Git Bash 提供命令执行环境；如果提示 git 不是内部或外部命令，请先安装 Git for Windows，安装后关闭并重新打开终端，再回到这里检查。

## 3 分钟主流程

### 第 1 步：安装 CSC

复制整行命令，粘贴到终端，按 Enter。等待安装结束并重新出现可输入命令的光标。

```bash
npm install -g @costrict/csc
```

判断：若末尾出现 `npm ERR!` 或安装中断，先看异常处理；普通提示信息不等于安装失败。

### 第 2 步：进入你的项目文件夹

CSC 会把"当前文件夹"当作工作范围。把下面路径换成你的项目路径：

```bash
cd /你的项目路径
```

不会找路径？先输入 `cd ` 和一个空格，再把项目文件夹拖进终端，最后按 Enter。没有项目也可以先建测试文件夹：`mkdir csc-test`，然后 `cd csc-test`。

### 第 3 步：启动 CSC

在项目目录里输入：

```bash
csc
```

成功时会进入 CSC 欢迎界面。以后每次使用，也是在目标项目目录里运行 `csc`。

### 第 4 步：登录并试一次

首次启动按提示登录，优先选择 **CoStrict 企业登录**（官方推荐）。没有出现登录步骤，就在 CSC 输入 `/login`。登录后输入下面的问题并发送：

> "用一句话概括这个项目的结构"

CSC 会按需读取项目文件，无需逐个添加。想换模型输入 `/model`；不知道选哪个就保留默认。登录凭据会保存，切换账户时再次输入 `/login`。

> **安装成功标准：** 同时满足 3 点：① 输入 `csc` 能打开界面；② 登录完成；③ 上面的问题能得到回答。

## 第一次使用，记住这 3 件事

- 你在哪个文件夹运行 `csc`，CSC 就主要在那个项目里工作；目录错了就先退出，再进入正确目录。
- 需要修改文件时，CSC 会展示建议并请求许可。看懂要改什么再批准；不确定就先拒绝或继续追问。
- 想看帮助输入 `/help`；退出可输入 `exit`，或按 `Ctrl+D`。

## 卡住了再看：异常处理

不要从头重装。先找到与你屏幕最像的一项，只执行对应处理。

| 你看到的情况 | 按这个顺序处理 |
|---|---|
| **A. 输入 npm 后提示找不到命令** | 电脑还没有可用的 Node.js / npm。打开 Node.js 官网，安装标有 LTS 的版本；安装后关闭并重新打开终端，再运行 `node -v` 和 `npm -v`。两行都有版本号后，回到第 1 步。 |
| **B. 安装时报 EACCES、permission denied 或权限不足** | **Windows：** 关闭终端，右键选择"以管理员身份运行"，再执行安装命令。**macOS / Linux：** 优先使用 Node 版本管理器重新安装 Node/npm，或按 npm 官方方法把全局目录改到用户目录；不要一上来就用 `sudo`。 |
| **C. 安装完成，但输入 csc 仍找不到命令** | 先关闭并重新打开终端，再输入 `csc`。仍失败：重新执行安装命令，确认末尾没有 `npm ERR!`；然后运行 `npm config get prefix`，把结果交给公司 IT，说明"npm 全局命令目录没有加入 PATH"。 |
| **D. 下载超时、连接失败或证书错误** | 先确认浏览器能联网，再重试原安装命令。公司网络、代理或 VPN 可能拦截 npm；可换网络测试，或请 IT 放行 `registry.npmjs.org`。不要随意关闭系统证书校验。 |
| **E. 启动后没有登录提示 / 登录中断** | 在 CSC 输入 `/login`，优先选择 CoStrict 企业登录。浏览器没有自动打开时，查看终端是否给出网址并手动打开；完成网页操作后回到终端。仍失败时确认 CoStrict 账户和公司网络可用。 |
| **F. CSC 打开了，但读到的不是目标项目** | 输入 `exit` 退出；在终端用 `cd` 进入正确的项目文件夹，再运行 `csc`。若不确定当前位置，macOS / Linux 输入 `pwd`，Windows PowerShell 输入 `Get-Location`。 |
| **G. Windows 启动 CSC 后执行命令失败，或提示找不到 bash / shell / git** | Windows 需要 Git for Windows 提供 Git Bash 环境。先在终端输入 `git --version`。如果提示找不到命令，请安装 Git for Windows；安装完成后关闭并重新打开终端，再重新运行 `git --version` 和 `csc`。如果 git 有版本号但仍失败，请把报错截图交给小助手蔻蔻，并说明："CSC 在 Windows 上需要 Git Bash 作为命令执行环境。" |

## 特殊登录：第三方 API 直连

这不是新手默认路径。只有管理员或服务商已经给你以下信息时再选：Base URL、API Key、Haiku Model、Sonnet Model、Opus Model。任何一项不知道，需要注册 CoStrict 账号使用。

> **安全提醒：** API Key 相当于密码，不要发到群聊、截图或写进项目代码。

## 需要重装或卸载

**重装 / 更新：** 再次执行主流程第 1 步的安装命令。

**彻底卸载：**
```bash
npm uninstall -g @costrict/csc
```
